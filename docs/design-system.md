# 幻画 AI 石墨工作台设计规范

> 版本：2.0
> 更新日期：2026-08-02
> 适用范围：Vue 客户端、Tauri 桌面端和后续新增的业务界面

## 1. 设计定位

幻画 AI 是面向高频图像创作的桌面工作台。界面采用“石墨黑创作台”风格：应用框架克制、参数信息紧凑、生成图片居中放大，视觉层级依靠明度、细边界和少量浮层建立，不依赖大面积渐变、实时背景模糊或装饰性阴影。

核心感受：

- **图片优先**：中央画布是创作页的视觉焦点，参数和导航退居两侧。
- **安静专业**：使用中性石墨表面和稳定分隔线，不把工具界面做成营销展示页。
- **多色语义**：蓝色负责主操作，青色负责媒体，绿色负责成功，暖橙负责积分，红色负责危险。
- **清晰稳定**：正文、边界、焦点和禁用状态在所有深色表面上保持可读。

## 2. 设计原则

1. 应用壳、侧栏、画布和参数区使用平面表面与 1px 分隔线，不包装为独立悬浮卡片。
2. 背景模糊只用于弹窗遮罩、弹窗主体和图片工具浮层。
3. 页面区段保持无框；卡片只承载模板、历史记录等独立重复内容。
4. 图片完整展示优先，默认使用 `object-fit: contain`，不能为了填满容器裁掉作品内容。
5. 所有状态至少通过颜色之外的一种信号表达，例如图标、边框或文字。
6. 动效只解释悬停、焦点、加载和弹窗层级，不使用持续漂浮或装饰性循环动画。

使用约束：

- 主按钮使用纯色 `--accent`，同一视图只保留一个主要操作。
- 暖橙、青色、绿色和红色只表达对应业务语义，不作为大面积主题色。
- 正文不得使用低于 `--muted` 的对比度。
- 应用背景保持纯色，不添加渐变球、光斑、噪点或无功能纹理。

## 4. 字体与信息层级

字体栈：`Avenir Next` / `SF Pro Display` / `PingFang SC` / 系统无衬线字体。桌面应用不依赖在线字体。

| 层级 | 建议字号 | 字重 | 用途 |
| --- | ---: | ---: | --- |
| 页面标题 | 22px | 660 | 历史、模板等页面标题 |
| 面板标题 | 18px | 660 | 参数栏、弹窗标题 |
| 卡片标题 | 13-14px | 620-680 | 模板和历史项目 |
| 正文 | 11-13px | 400-600 | 表单、说明、操作 |
| 元信息 | 9-10px | 500-700 | 时间、积分、分类 |

全部文字 `letter-spacing: 0`。标题不得使用随视口变化的字号，紧凑工具面板中不使用展示型大标题。

## 5. 表面与层级

### 5.1 应用框架

顶部栏、图标栏、画布和参数栏使用不透明石墨表面。层级由背景明度和 `--line` 分隔，不使用实时模糊、方向性渐变或外部重阴影。

### 5.2 重复内容

模板卡片、历史记录、套餐和输入控件使用 `--surface-raised` 或 `--surface-subtle`。卡片圆角最大 8px，卡片内部不再嵌套同类装饰卡片。

### 5.3 浮层

tooltip、图片操作和弹窗可以使用轻量背景模糊。弹窗最大模糊约 18px，并配合 `--line-strong` 和克制阴影建立层级。

### 5.4 桌面应用图标

- 发布母版固定为 1024×1024 PNG，圆角底板外保留透明区域，不允许使用铺满画布的不透明方形背景。
- macOS 圆角底板为居中的 824×824，外边距约 100px，圆角约 185px；底色使用 `#0A0918`，边缘使用克制描边和阴影。
- 主标志使用开放渐变圆环、下方弧线和单个暖色高光；小尺寸需要保持粗笔画，确保 24px 下三个元素仍可分辨。
- 图标不添加文字、山景、画笔、徽标角标、白色外框、光晕或场景化背景。可编辑母版位于 `src-tauri/app-icon.svg`，无底板品牌标记 `src/assets/huanhua-mark.svg`、1024×1024 PNG 和 Tauri 桌面资源均由该文件派生。

## 6. 布局

- 应用内容贴合原生窗口边缘，不设置外边距、外圈描边或外圈圆角。
- 顶部标题栏：48px，产品名在整个窗口水平方向居中；标题标记使用由 `src-tauri/app-icon.svg` 主标志派生的无底板 `src/assets/huanhua-mark.svg`，固定为 24×24px，侧栏不重复品牌标记。
- macOS 桌面端使用原生标题栏 Overlay，并固定为深色系统外观，使失焦窗口按钮在石墨黑标题栏上仍保持清晰；系统窗口按钮与产品名共享顶部栏，浏览器预览不绘制仿系统按钮。
- Windows 桌面端隐藏原生标题栏、左上角应用图标和名称，在应用顶部栏右侧绘制最小化、最大化/还原和关闭按钮；保留窗口拖动、双击最大化、边缘吸附和无边框缩放能力。
- 桌面图标栏：60px；菜单按钮 40×40px。
- 生成工作区：中央结果画布占剩余宽度，右侧参数栏使用 `clamp(340px, 23vw, 372px)`。
- 画布和参数栏之间仅保留 1px 分隔线，不设置卡片间距。
- Tauri 启动时默认最大化并占满当前屏幕可用工作区，不进入隐藏系统栏的全屏模式；还原尺寸为 1520×920，最小窗口为 1080×720。
- 900px 以下使用抽屉导航，并在抽屉内直接显示菜单文字；生成画布和参数区改为单列。
- 主要间距单位：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32px。

固定格式控件必须有稳定尺寸。比例按钮、图标按钮、tooltip、模板预览和结果画布不能因文字、加载或登录状态改变外框大小。

## 7. 组件规范

### 顶部栏与导航

- 顶部固定显示产品名“幻画 AI”，页面名称保留在各自内容区。
- 顶部栏作为 Tauri 原生拖拽区域；产品名不得拦截拖拽，也不能因左侧系统窗口按钮而偏离窗口中心。
- Windows 窗口按钮使用 46px 宽的矩形命中区并贴合窗口右上角；最大化状态变化时同步切换为还原图标，关闭按钮使用系统危险色悬停反馈。
- 桌面侧栏只显示 Lucide 图标；文字通过右侧 tooltip 在 hover 和 focus 时出现，不能推动布局。
- 主导航上方分为两组并使用 1px 灰色横线分隔：第一组依次为文生图、图生图、AI 抠图、自动分层、模板广场、历史记录，第二组依次为图片压缩、图片编辑。图片压缩只在 Tauri 桌面端显示；浏览器隐藏图片压缩后，图片编辑仍作为第二组首项显示。AI 抠图也可从文生图、图生图的结果区域或图片编辑页右键菜单进入。
- 当前导航项使用蓝色图标、半透明蓝色背景和强调边界。
- 未登录时侧栏底部显示登录入口；登录后显示设置，积分余额移至标题栏右侧并可打开积分记录。检测到普通更新后，在登录或设置入口上方显示绿色更新图标，点击后打开更新弹窗；强制更新仍自动打开弹窗。
- 侧栏底部操作区不使用顶部分割线，依靠位置和间距与主导航区分。
- 标题栏积分入口默认不显示边框和背景，只在 hover 与 focus-visible 时显示暖色边界和底色，交互前后尺寸保持不变。
- 图标按钮必须提供 `aria-label`，tooltip 只负责视觉提示。

### 按钮与表单

- 主按钮用于生成、保存等明确提交操作；次按钮用于充值、刷新等相关操作。
- 熟悉的工具操作优先使用图标按钮，不用文字胶囊替代图标。
- 输入高度 42px，圆角 7px；聚焦使用 1px 蓝色边界和低透明度焦点环。
- 单选集合使用分段控制外观，原生 input 继续保留键盘和读屏语义。
- 生成积分不足时，主按钮使用暖色禁用态并直接显示积分缺口；其他生成错误在按钮上方使用带警示图标的高对比提示块。
- 输出格式使用三段控制；JPEG/WebP 的压缩率使用固定高度的 0–100 滑杆，PNG 无损输出时不显示压缩率控件。
- hover 只改变颜色、边界和轻量阴影，不能产生布局位移。

### 生成画布

- 单图与结果容器固定保持 14px 边距，完整居中，不裁切、不放大溢出。
- 多图使用稳定的两列网格，较窄视口切换单列。
- 加载状态占用完整画布尺寸，避免生成前后布局跳动。
- 未开始任务时使用固定尺寸的大号生成图标或画框插画，明确区分文生图与图生图，不显示输出尺寸或比例；空闲态只使用一次入场动效，不使用持续循环动画。
- 图片工具统一位于结果区域右上角，使用高对比小型浮层；下载只保留一个入口，默认保存位置为空时不显示文件夹按钮。
- 文生图与图生图结果图片的右键菜单提供复制、下载、图生图和 AI 抠图，使用紧凑石墨浮层并限制在窗口可视范围内；支持 Escape、方向键、Home 和 End 操作。
- 当前工作区未绑定生成任务时，最近一个进行中任务以紧凑入口显示在预览区域右上角；入口同时显示生成模式和状态，点击后恢复任务预览。
- 切换文生图与图生图会清空当前预览、参考图和临时表单值，并恢复用户设置的默认参数；不得自动回显该模式的最近历史结果。
- 图生图右侧栏允许上传 1–3 张参考图；已有参考图使用三列固定比例缩略图网格，显示当前数量并在未满时保留“添加”入口。每张图可独立预览和删除，单文件大小限制沿用服务端能力值。
- 结果区不提供重新生成入口；当前模式存在成功任务结果时，参数栏主按钮显示“重新生成”并继续沿用生成提交流程。
- 结果区使用复制按钮替代放大占位；右上角悬浮图标栏提供编辑与 AI 抠图入口，复制、下载、图生图和 AI 抠图始终针对当前显示版本。
- 生成结果区的编辑按钮读取当前结果后直接跳转到 `/editor`，不得创建 Teleport、遮罩或弹窗；结果空闲时预热运行时与当前原图，减少跳转后的等待时间。
- 图片编辑支持裁剪、90° 旋转、水平翻转、亮度/对比度/饱和度/灰度、文字、画笔、橡皮擦、撤销、重做和恢复原图。工具栏仅保留一个“翻转”入口并执行水平翻转。裁剪面板以原图坐标系的整数像素实时显示选区宽高，允许手动输入 `1..当前图片边长`；输入任一尺寸会切换到自由比例、保持选区中心并将选区整体约束回图片范围。裁剪使用连续遮罩突出保留区域，边缘拖动允许约 4px 容差并在松手后精确吸附；选区使用内描边，控制点向选区内偏移，贴住四边或四角时仍完整可见。文字对象的右键菜单提供删除操作；画笔与橡皮擦在画布上使用和实际笔触范围一致的圆形光标，并随颜色和粗细即时更新；橡皮擦只清除标注，不删除原图像素。
- 图片画布以适应视图为 100%，支持 25%–400% 缩放、滚轮按指针位置缩放和拖动工具平移。缩放与位移必须同时作用于底图、裁剪框和全部标注，只属于预览状态，不进入编辑文档、撤销历史或导出尺寸。
- 应用编辑只更新图片编辑页内的临时结果，不修改生成结果预览、服务端任务和创作历史；离开编辑页后释放临时图片。

### 页面、卡片与弹窗

- 模板和历史页面保持无框，只由页头分隔线建立结构；图片编辑页不显示独立页头，进入后直接占满可用内容区。
- 独立图片编辑页使用本地 PNG、JPEG 或 WebP，并沿用生成页的两栏结构，不使用外边距、Teleport 或弹窗：主内容区内是 44px 单列工具栏和透明棋盘画布，工具按钮无外层边距，悬停与选中背景覆盖整行；右侧栏只承载图片尺寸、当前工具属性及底部“应用编辑”按钮，不显示更换图片、复制或另存为按钮。页面不显示底部状态栏。无图片时保持两栏尺寸，禁用编辑工具，主内容区显示带边框的透明棋盘投放面和“拖放图片”文字；整块投放面支持点击选图和文件拖放，拖入时只改变边界与文字颜色，不改变布局尺寸。应用后工作台保持挂载并将当前状态设为新的已应用基线；图片右键菜单提供复制与另存为并使用最近一次已应用结果。生成结果通过一次性内存交接进入该页面；编辑文档、原图和导出 Blob 只在当前页面存活，离开页面后释放且不写入全局状态或创作历史。
- AI 抠图页（`/cutout`）沿用生成页的两栏结构（左画布、右结果区），不显示页头与底部状态栏。页面始终显示 44px 单列工具栏与整块透明棋盘画布；左上第一个 `ImageDown` 图标为“导入图片”按钮，点击后直接打开图片选择器，自动分层页沿用同一布局。第二个图标使用 `ScanSearch` 提供“智能框选”，只在桌面端和已载入图片时启用，运行时原位显示旋转进度。鼠标悬停或键盘聚焦该按钮时，在右侧显示 220px 紧凑筛选浮层；“智能框选强度”滑杆以“更多/更少”标示方向，显示当前百分比，范围 `80%–99%`、默认 `95%`，运行期间禁用但不改变布局。智能框选复用 SAM 2.1 自动提议，只替换为最多 32 个去重后的元素矩形，不直接抠图或分层；每个框按长边 8% 向四周外扩且单边限制为 8–32px，覆盖描边、阴影和遮罩边界误差。已有选区时必须确认，整次替换进入一条撤销记录。其余工具包含框选、点选轮廓、背景修复和拖动，另含清空图片、缩放、撤销/重做和清除选区。点选轮廓使用原图坐标保存多边形顶点，点击起点、双击或 Enter 闭合，Backspace 撤回最后一点，Escape 取消；草稿使用蓝色虚线和固定屏幕尺寸锚点，闭合后以外接框裁剪提示 BiRefNet 提取内部元素，ViTMatte 精修后把最终 Alpha 限制在多边形内。背景修复属性使用工具栏右侧紧凑浮层，只提供智能吸附和笔刷大小，智能吸附默认关闭；圆形光标与图像坐标系笔刷半径一致。没有选区或未命中选区时保留普通鼠标且不显示圆形笔刷；命中任意选区时立即显示笔刷并允许直接涂抹，无需预先激活目标，首次笔画同时把该选区标记为背景修复并只记录一条撤销历史。绘制框为蓝色虚线，素材框为蓝色实线，背景框为暖色实线；多边形使用对应语义色实线和弱透明填充，并保留低对比度外接框作为移动与删除操作范围。选区上不显示编号或“素材/背景”文字，右上角删除按钮仅在鼠标悬停或键盘聚焦选区时出现。框选或点选工具下拖动边界可移动选区，矩形框内空白仍用于绘制嵌套框；移动松手后重算父子关系并只记录一条撤销历史。框选与框选文字工具激活时，按住鼠标右键拖动可平移画布（等效拖动工具），平移期间不弹出系统右键菜单。嵌套关系仍按外接框几何关系自动建立最近父级。自动分层模式继续只显示智能框选、元素框、文字框和拖动，不提供多边形点选与背景修复。
- AI 抠图的点选轮廓、矩形框与自动分层的元素框共用同一个 BiRefNet -> 闭合面板先验 -> trimap -> ViTMatte 链路：BiRefNet 每个选区单次前向输出软 alpha，多边形仅提供更贴合物体的外接框裁剪提示，不做候选选择与孔洞支持恢复；trimap 仅在裁剪区边界颜色高度集中且粗 Alpha 也支持背景时，把裁剪区内同色像素设为确定背景，以保留纯色底上的透明孔洞；精修后再仅对该分支的未知带执行局部前景/背景色混合约束，降低近背景色像素的异常 Alpha，不改确定前景。普通照片和前景铺边场景不启用这些规则；最终 Alpha 在导出前限制在对应选区内。同一选区的粗分割与精修保持串行依赖；多选区且设备至少有 8 个逻辑核时，两个独立原生会话按单任务阶段组成流水线，使上一选区精修与下一选区粗分割重叠，低核设备保持逐选区串行。SAM 只用于“智能框选”生成可编辑矩形；智能笔刷在 BiRefNet 链路下降级为纯几何 add/restore 笔画。
- 自动分层页（`/auto-layer`）默认让原图工作区占满可用宽度；云修复成功前不挂载结果预览，失败草稿只允许重试背景。完成后右侧结果抽屉自动展开，且默认不选中任何图层。`>=900px` 默认 50/50，使用 8px 垂直分隔线在 25%–75% 范围拖动调整，也支持方向键、Home 和 End；`<900px` 结果面板占满工作区并提供明确关闭按钮。Escape 或“收起结果”触发轨道收缩、位移与淡出动画，reduced-motion 下取消动画。左侧 44px 工具栏显示“智能框选”“框选元素”“框选文字”“拖动”，页面底部统一操作栏放置保存选区、选区记录、打包保存、抽屉开关和主操作。“打包保存”打开向上菜单，包含“保存为 PSD”和“保存为文件夹”，支持 Escape、方向键、Home、End 与点击外部关闭。PSD 必须保留当前画布尺寸、图层位置和尺寸、前后顺序、显隐及父子图层组，背景固定为根级最底层，文字同时包含当前外观像素和可编辑文字描述。结果属性区的“还原全部位置与大小”一次恢复所有图层的原始框选坐标和尺寸；保存为文件夹允许在用户选择的目录下创建项目目录及资源子目录。有直接子层的父素材会生成局部修复裁片，并与整页背景区优先打入同一张云端图集；只有统一缩放将低于质量阈值时才弹出确认并拆分为整页背景与父素材两张独立图集。
- 自动分层推理中，元素框直接调用 AI 抠图的共享 BiRefNet/ViTMatte 函数，粗分割、闭合面板先验、精修和选区约束保持一致；文字层以 OCR 行为单位并强制单行。初始层级保证父层在全部后代下方；每个父级只合并直接子层的高召回 Alpha，文字使用实际字形 Alpha 做 2–4px 有界扩张。存在直接子层移除蒙版的父素材统一使用本地 Big-LaMa 修复，整页背景继续使用独立的本地草稿与复杂背景云修复分流。结果画布不显示选框、焦点框或缩放手柄，选中反馈只出现在图层列表与属性区；素材使用移动指针，文字使用文本指针。画布支持拖动、键盘微调、显隐、层级与文字就地编辑，20%–400% 缩放统一由属性区滑杆完成。
- 自动分层质量规则：精修 Alpha 确实越过紧选框边缘时，只向对应方向小幅扩展素材边界。普通中文 UI 与描边小字默认使用字重 `400`，极强粗体证据才提升到 `600`，自动识别不输出 `700`。云端输入在提交前清除图集联合蒙版内的 Alpha 与隐藏 RGB，服务端只在各分区的原蒙版内合成一次；客户端拆分时直接采用已合成 RGB 并保留素材 Alpha，禁止再次按软蒙版混合。纯色或缓渐变背景（蒙版邻域背景颜色集中度达到扩散阈值）由客户端直接扩散提取背景，不创建云端图集、不消耗积分，蒙版区域不会出现生成模型臆造的内容；复杂照片背景才创建云端 inpainting 图集。
- 图片压缩页（`/compress`）使用“主列表 + 340px 右侧结果栏”的平面工作台，区域之间仅用 1px 分隔线，不使用页面卡片。主列表页头固定显示添加图片、选择文件夹、重试失败项和清空操作；空状态是单一虚线投放面，导入后切换为紧凑表格，稳定展示缩略图、格式、相对路径、尺寸、原始大小、状态、输出大小和节省比例。缩略图固定为 42×42px 并只在接近可视区时加载；鼠标悬停或键盘聚焦显示不超过 320×320px 的完整预览，浮层必须避让窗口边缘且不受列表滚动裁切，Escape、失焦、离开和滚动均可关闭。透明图片使用棋盘背景，格式标签使用青、暖橙和蓝色辅助区分，但必须同时保留 PNG/JPEG/WebP 文字。
- 压缩结果栏在处理前不要求或展示输出文件夹，只显示逐项结果；底部主操作与进度区固定，不随列表滚动。压缩完成后主操作切换为“保存结果”，点击后才打开系统目录选择器。文件模式把所选目录作为输出根；文件夹模式把所选目录作为父目录，自动创建独立的 `<源文件夹名>-压缩` 目录并保留源相对层级，同名目录增加编号，结果不得直接散落在所选父目录。保存成功在工作区顶部正中显示可关闭、自动消失的 Toast，不在右栏常驻展示保存数量或目标目录，自动重命名后的真实文件名保留在对应结果项，保存失败项直接显示原因。右栏设置按钮打开独立弹窗，弹窗只配置同名策略和无收益写出行为；格式与质量由原生端固定的单次有损策略决定，不显示格式标签、质量滑杆或无损开关。默认同名策略为自动重命名。原生端自动使用 1–4 个受限工作线程并按格式与最大图片尺寸降低并发，不向用户暴露线程设置。处理状态显示最近启动项的相对路径、完成数、线性进度和 `aria-live` 文本；失败、跳过、无收益、取消及保存结果都必须有明确文字。900px 以下改为列表在上、结果栏在下的单列布局，桌面 1520×920 与最小 1080×720 下保持双栏。
- AI 抠图正式界面固定使用本地背景修复，不显示本地/云端分段控制。本地 Big-LaMa 未安装时显示独立按需下载提示，不与分割模型 + ViTMatte 资源提示合并。所有非空背景修复蒙版统一使用 Big-LaMa，手工笔画、智能吸附、子素材移除、纯色、渐变和闭合 UI 面板不再切换确定性曲面/扩散；自动分层的整页背景不属于该链路。修复区域超过模型输入尺寸时按 512×512 瓦片原生分辨率分块、重叠带羽化合成，避免整框缩到 512 导致的模糊。结果列表使用文字标签区分“素材/背景”，继续使用透明棋盘缩略图和不裁切的悬浮预览。推理状态保留兼容的上传与云端等待文案，但正式 AI 抠图只进入本地分割、精修与修复阶段；“一键抠图”只在本地所需资源、图片、选区、登录和积分均有效时启用。普通独立素材使用 BiRefNet + ViTMatte 链路；背景素材的子级移除蒙版合并 ViTMatte Alpha 与 BiRefNet 弱响应，并按子元素长边 2.5% 扩张（4–18 px），之后只在该蒙版内合成修复 RGB，并以父级 Alpha 作为最终透明边界。完整成功任务将选区关系和矢量笔画写入桌面本地历史。
- 模板广场和模板选择弹窗使用紧凑页头、连续分类工具栏和按图片比例排列的响应式瀑布流；常规桌面固定为四列，较窄窗口自动降为三列、两列或单列。模板按原始顺序循环分入各列，每组首张模板固定从最左列开始，卡片宽度填满列。模板广场的媒体区最高为 `min(48vh, 460px)`，文生图和图生图预览统一使用 `object-fit: contain` 完整显示，空余区域使用 `--field` 背景，避免单张竖图拉高整个页面；模板选择弹窗继续按真实预览比例展示。标题、提示词、分类和“使用”按钮在 hover、focus-within 或触屏环境下显示于图片底部浮层。
- 图生图模板在同一画面内叠放原图与生成结果，使用默认位于左侧 15% 的可拖动垂直分割线连续对比；对比控件必须支持鼠标、触屏和键盘方向键/Home/End，原图与生成结果标签始终可见。对比容器跟随生成结果比例，两张图片使用一致的完整显示规则，保证分割线两侧不拉伸、不裁切。
- 模板卡片的提示词最多显示两行；套用模板使用仅显示“使用”的紧凑按钮，不能占据整行。
- 创作历史沿用模板广场的页头和三段式 tab 控制，依次展示文生图、图生图和 AI 抠图；三类任务统一使用 264×264px 固定卡片的规则网格。文生图与图生图结果按原始比例铺满卡片并允许居中裁切，提示词、积分消耗、创建时间、尺寸和复制提示词入口在 hover、focus-within 或触屏环境下显示于图片底部浮层；抠图任务继续完整展示透明素材，在固定卡片内使用透明棋盘拼贴最多四个结果，任务状态叠放在图片右上角。
- 历史任务卡右键菜单依次提供“打开任务”“复制”“保存”“图生图”，四项操作使用同一菜单层级；后三项针对首张结果图，无结果图片时保持可见禁用。菜单打开时不预选或高亮任何操作，只在悬停或键盘导航时显示交互反馈；浮层限制在窗口可视范围内，并支持 Escape、方向键、Home、End、菜单键和 Shift+F10。打开任务会进入对应生成模式并恢复提示词、生成参数、全部图生图参考图和服务端结果图片；图生图动作进入新的图生图工作区并以所选结果作为第一张参考图。
- 点击任意历史任务进入多选状态，失败或无图片任务也可选择；选中卡片同时使用强调边界和勾选标记。底部始终提供删除和取消选择，仅当所选任务均有结果图片时显示描边样式的批量下载按钮；页头不提供清空历史入口。
- AI 抠图历史仅在 Tauri 桌面端保存，包含原图、图像坐标系选区和全部透明结果，最多保留最近 100 条。右键菜单只提供“恢复工作”和“保存全部素材”；恢复后立即显示原图、选区和已有结果，修改选区清空旧结果，再次抠图重新扣费并新增记录。浏览器预览不实现抠图历史持久化或模拟记录。
- 历史分页每页 12 项，使用首尾页、前后页和有限页码按钮；切换文生图或图生图时回到第一页。
- 弹窗使用清晰标题和关闭图标；高度超过视口时只滚动内容区。
- 新弹窗必须支持 Escape、基础焦点管理、`role="dialog"` 和标题关联。
- 更新弹窗使用单一石墨表面、版本对比和线性进度。普通更新可稍后，强制更新不显示关闭操作且 Escape 无效；下载、安装、错误和重启必须同时使用图标或文字表达，不能只靠颜色。

- 自动分层双栏结果展开时，原图与结果画布共同采用两侧自然适配比例的较小值，在 100% 适配状态下保持相同显示尺寸；分隔线变化后实时重算，用户主动缩放原图时仍允许独立查看。

## 8. 动效

- 常规交互：160-180ms ease。
- 抽屉导航：220ms ease。
- 模态框：200ms，轻微位移与透明度变化。
- shimmer 只在真实加载期间运行。
- 必须遵守 `prefers-reduced-motion: reduce`，禁用非必要动画。

## 9. 可访问性

- 交互元素必须可通过键盘到达，并保留可见焦点环。
- 正文与表面目标对比度至少 4.5:1；大字至少 3:1。
- tooltip 同时响应 hover 和 focus，但不能作为唯一可访问名称。
- 不使用颜色作为唯一状态信号。
- 图片提供描述用途的 alt；装饰图标由按钮标签承接语义或隐藏。
- 支持 `prefers-contrast: more`，提高边界与辅助文字对比度。

## 10. 实现约定

- `src/styles/main.scss` 仅通过 `@use` 聚合全局样式，不直接承载具体规则。
- `src/styles/_tokens.scss` 定义主题 tokens，`_foundation.scss` 提供重置与基础表单，`_controls.scss` 提供公共控件，`_patterns.scss` 提供页面、空状态和弹窗等复用模式。
- App、路由 view 和功能组件的私有布局、外观与响应式规则放在对应 SFC 的 `<style scoped lang="scss">` 中。
- 新组件优先复用现有语义类和 tokens，不新增硬编码主题颜色；只有跨两个及以上组件稳定复用的规则才进入 `src/styles/`。
- 不引入 Tailwind、新组件库、在线字体或 Emoji 功能图标。
