# 幻画 AI 石墨工作台设计规范

> 版本：2.0
> 更新日期：2026-07-19
> 适用范围：Vue 客户端、Tauri 桌面端和后续新增的业务界面

## 1. 设计定位

幻画 AI 是面向高频图像创作的桌面工作台。界面采用“石墨黑创作台”风格：应用框架克制、参数信息紧凑、生成图片居中放大，视觉层级依靠明度、细边界和少量浮层建立，不依赖大面积渐变、实时背景模糊或装饰性阴影。

核心感受：

- **图片优先**：中央画布是创作页的视觉焦点，参数和导航退居两侧。
- **安静专业**：使用中性石墨表面和稳定分隔线，不把工具界面做成营销展示页。
- **多色语义**：蓝色负责主操作，青色负责媒体，绿色负责成功，暖橙负责积分，红色负责危险。
- **清晰稳定**：正文、边界、焦点和禁用状态在所有深色表面上保持可读。

## 2. 设计原则

1. 应用壳、侧栏、画布和参数区使用平面表面与 1px 分隔线，不包装为独立悬浮卡片。
2. 背景模糊只用于弹窗遮罩、弹窗主体和图片工具浮层。
3. 页面区段保持无框；卡片只承载模板、历史记录等独立重复内容。
4. 图片完整展示优先，默认使用 `object-fit: contain`，不能为了填满容器裁掉作品内容。
5. 所有状态至少通过颜色之外的一种信号表达，例如图标、边框或文字。
6. 动效只解释悬停、焦点、加载和弹窗层级，不使用持续漂浮或装饰性循环动画。

使用约束：

- 主按钮使用纯色 `--accent`，同一视图只保留一个主要操作。
- 暖橙、青色、绿色和红色只表达对应业务语义，不作为大面积主题色。
- 正文不得使用低于 `--muted` 的对比度。
- 应用背景保持纯色，不添加渐变球、光斑、噪点或无功能纹理。

## 4. 字体与信息层级

字体栈：`Avenir Next` / `SF Pro Display` / `PingFang SC` / 系统无衬线字体。桌面应用不依赖在线字体。

| 层级 | 建议字号 | 字重 | 用途 |
| --- | ---: | ---: | --- |
| 页面标题 | 22px | 660 | 历史、模板等页面标题 |
| 面板标题 | 18px | 660 | 参数栏、弹窗标题 |
| 卡片标题 | 13-14px | 620-680 | 模板和历史项目 |
| 正文 | 11-13px | 400-600 | 表单、说明、操作 |
| 元信息 | 9-10px | 500-700 | 时间、积分、分类 |

全部文字 `letter-spacing: 0`。标题不得使用随视口变化的字号，紧凑工具面板中不使用展示型大标题。

## 5. 表面与层级

### 5.1 应用框架

顶部栏、图标栏、画布和参数栏使用不透明石墨表面。层级由背景明度和 `--line` 分隔，不使用实时模糊、方向性渐变或外部重阴影。

### 5.2 重复内容

模板卡片、历史记录、套餐和输入控件使用 `--surface-raised` 或 `--surface-subtle`。卡片圆角最大 8px，卡片内部不再嵌套同类装饰卡片。

### 5.3 浮层

tooltip、图片操作和弹窗可以使用轻量背景模糊。弹窗最大模糊约 18px，并配合 `--line-strong` 和克制阴影建立层级。

### 5.4 桌面应用图标

- 发布母版固定为 1024×1024 PNG，圆角底板外保留透明区域，不允许使用铺满画布的不透明方形背景。
- macOS 圆角底板为居中的 824×824，外边距约 100px，圆角约 185px；底色使用 `#0A0918`，边缘使用克制描边和阴影。
- 主标志沿用 `src-tauri/icons/favicon.svg` 的开放渐变圆环、下方弧线和单个暖色高光；小尺寸需要保持粗笔画，确保 32px 下三个元素仍可分辨。
- 图标不添加文字、山景、画笔、徽标角标、白色外框、光晕或场景化背景。可编辑母版位于 `src-tauri/app-icon.svg`，1024×1024 PNG 和 Tauri 桌面资源均由该文件派生。

## 6. 布局

- 应用内容贴合原生窗口边缘，不设置外边距、外圈描边或外圈圆角。
- 顶部标题栏：48px，产品名在整个窗口水平方向居中；标题标记使用 `src/assets/huanhua-mark.svg` 中的无底板品牌符号，固定为 24×24px，侧栏不重复品牌标记。
- macOS 桌面端使用原生标题栏 Overlay，并固定为深色系统外观，使失焦窗口按钮在石墨黑标题栏上仍保持清晰；系统窗口按钮与产品名共享顶部栏，浏览器预览不绘制仿系统按钮。
- Windows 桌面端隐藏原生标题栏、左上角应用图标和名称，在应用顶部栏右侧绘制最小化、最大化/还原和关闭按钮；保留窗口拖动、双击最大化、边缘吸附和无边框缩放能力。
- 桌面图标栏：60px；菜单按钮 40×40px。
- 生成工作区：中央结果画布占剩余宽度，右侧参数栏使用 `clamp(340px, 23vw, 372px)`。
- 画布和参数栏之间仅保留 1px 分隔线，不设置卡片间距。
- Tauri 默认窗口为 1520×920，最小窗口为 1080×720。
- 900px 以下使用抽屉导航，并在抽屉内直接显示菜单文字；生成画布和参数区改为单列。
- 主要间距单位：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32px。

固定格式控件必须有稳定尺寸。比例按钮、图标按钮、tooltip、模板预览和结果画布不能因文字、加载或登录状态改变外框大小。

## 7. 组件规范

### 顶部栏与导航

- 顶部固定显示产品名“幻画 AI”，页面名称保留在各自内容区。
- 顶部栏作为 Tauri 原生拖拽区域；产品名不得拦截拖拽，也不能因左侧系统窗口按钮而偏离窗口中心。
- Windows 窗口按钮使用 46px 宽的矩形命中区并贴合窗口右上角；最大化状态变化时同步切换为还原图标，关闭按钮使用系统危险色悬停反馈。
- 桌面侧栏只显示 Lucide 图标；文字通过右侧 tooltip 在 hover 和 focus 时出现，不能推动布局。
- 主导航顺序为文生图、图生图、AI 抠图、模板广场、历史记录；AI 抠图也可从文生图、图生图的结果区域或图片编辑页右键菜单进入，图片编辑不在桌面图标栏或移动抽屉中展示。
- 当前导航项使用蓝色图标、半透明蓝色背景和强调边界。
- 未登录时侧栏底部显示登录入口；登录后显示设置，积分余额移至标题栏右侧并可打开积分记录。检测到普通更新后，在登录或设置入口上方显示绿色更新图标，点击后打开更新弹窗；强制更新仍自动打开弹窗。
- 侧栏底部操作区不使用顶部分割线，依靠位置和间距与主导航区分。
- 标题栏积分入口默认不显示边框和背景，只在 hover 与 focus-visible 时显示暖色边界和底色，交互前后尺寸保持不变。
- 图标按钮必须提供 `aria-label`，tooltip 只负责视觉提示。

### 按钮与表单

- 主按钮用于生成、保存等明确提交操作；次按钮用于充值、刷新等相关操作。
- 熟悉的工具操作优先使用图标按钮，不用文字胶囊替代图标。
- 输入高度 42px，圆角 7px；聚焦使用 1px 蓝色边界和低透明度焦点环。
- 单选集合使用分段控制外观，原生 input 继续保留键盘和读屏语义。
- 生成积分不足时，主按钮使用暖色禁用态并直接显示积分缺口；其他生成错误在按钮上方使用带警示图标的高对比提示块。
- 输出格式使用三段控制；JPEG/WebP 的压缩率使用固定高度的 0–100 滑杆，PNG 无损输出时不显示压缩率控件。
- hover 只改变颜色、边界和轻量阴影，不能产生布局位移。

### 生成画布

- 单图与结果容器固定保持 14px 边距，完整居中，不裁切、不放大溢出。
- 多图使用稳定的两列网格，较窄视口切换单列。
- 加载状态占用完整画布尺寸，避免生成前后布局跳动。
- 未开始任务时使用固定尺寸的大号生成图标或画框插画，明确区分文生图与图生图，不显示输出尺寸或比例；空闲态只使用一次入场动效，不使用持续循环动画。
- 图片工具统一位于结果区域右上角，使用高对比小型浮层；下载只保留一个入口，默认保存位置为空时不显示文件夹按钮。
- 文生图结果图片的右键菜单提供复制、下载和图生图，使用紧凑石墨浮层并限制在窗口可视范围内；支持 Escape、方向键、Home 和 End 操作。
- 当前工作区未绑定生成任务时，最近一个进行中任务以紧凑入口显示在预览区域右上角；入口同时显示生成模式和状态，点击后恢复任务预览。
- 切换文生图与图生图会清空当前预览、参考图和临时表单值，并恢复用户设置的默认参数；不得自动回显该模式的最近历史结果。
- 结果区不提供重新生成入口；当前模式存在成功任务结果时，参数栏主按钮显示“重新生成”并继续沿用生成提交流程。
- 结果区使用复制按钮替代放大占位；复制、下载和文生图右键“图生图”始终针对当前显示版本。
- 生成结果区的编辑按钮读取当前结果后直接跳转到 `/editor`，不得创建 Teleport、遮罩或弹窗；结果空闲时预热运行时与当前原图，减少跳转后的等待时间。
- 图片编辑支持裁剪、90° 旋转、水平翻转、亮度/对比度/饱和度/灰度、文字、画笔、橡皮擦、撤销、重做和恢复原图。工具栏仅保留一个“翻转”入口并执行水平翻转。裁剪面板以原图坐标系的整数像素实时显示选区宽高，允许手动输入 `1..当前图片边长`；输入任一尺寸会切换到自由比例、保持选区中心并将选区整体约束回图片范围。裁剪使用连续遮罩突出保留区域，边缘拖动允许约 4px 容差并在松手后精确吸附；选区使用内描边，控制点向选区内偏移，贴住四边或四角时仍完整可见。文字对象的右键菜单提供删除操作；画笔与橡皮擦在画布上使用和实际笔触范围一致的圆形光标，并随颜色和粗细即时更新；橡皮擦只清除标注，不删除原图像素。
- 图片画布以适应视图为 100%，支持 25%–400% 缩放、滚轮按指针位置缩放和拖动工具平移。缩放与位移必须同时作用于底图、裁剪框和全部标注，只属于预览状态，不进入编辑文档、撤销历史或导出尺寸。
- 应用编辑只更新图片编辑页内的临时结果，不修改生成结果预览、服务端任务和创作历史；离开编辑页后释放临时图片。

### 页面、卡片与弹窗

- 模板和历史页面保持无框，只由页头分隔线建立结构；图片编辑页不显示独立页头，进入后直接占满可用内容区。
- 独立图片编辑页使用本地 PNG、JPEG 或 WebP，并沿用生成页的两栏结构，不使用外边距、Teleport 或弹窗：主内容区内是 44px 单列工具栏和透明棋盘画布，工具按钮无外层边距，悬停与选中背景覆盖整行；右侧栏只承载图片尺寸、当前工具属性及底部“应用编辑”按钮，不显示更换图片、复制或另存为按钮。页面不显示底部状态栏。无图片时保持两栏尺寸，禁用编辑工具，主内容区显示带边框的透明棋盘投放面和“拖放图片”文字；整块投放面支持点击选图和文件拖放，拖入时只改变边界与文字颜色，不改变布局尺寸。应用后工作台保持挂载并将当前状态设为新的已应用基线；图片右键菜单提供复制与另存为并使用最近一次已应用结果。生成结果通过一次性内存交接进入该页面；编辑文档、原图和导出 Blob 只在当前页面存活，离开页面后释放且不写入全局状态或创作历史。
- AI 抠图页（`/cutout`）沿用生成页的两栏结构（左画布、右结果区），不显示页头与底部状态栏。页面无独立拖入提示状态，进入后始终显示 44px 单列工具栏与整块透明棋盘画布；无图片时仅禁用需要图片的工具，通过左侧导入按钮或画布文件拖放载入图片。工具栏只保留框选与拖动，不展示无效选择工具；另含导入/清空图片、缩放、撤销/重做和清除选区。绘制中的框使用半透明蓝色填充与虚线描边，已完成框使用实线边界；多个框选并存，连续序号固定在框内左上角，右上角图标可删除单框。右侧不显示模型列表、档位名称或模型开关；仅在检测到统一资源包不完整时显示一次紧凑下载提示和连续总进度，SAM ViT-H 与 ViTMatte 均就绪后整个提示隐藏。结果缩略图使用透明棋盘背景展示真实内容，推理中按阶段显示“正在分割 N/M”或“正在精修 N/M”。“一键抠图”只在图片、选区和完整资源包均有效时启用；推理由 Tauri/Rust 原生 ONNX Runtime 执行，decoder 选择最高 IoU 候选并输出软 alpha，随后固定使用 ViTMatte 与带上下文的三值 trimap 修复轮廓和主体内部缺口，前端双线性恢复后与原图 alpha 合成。每个选区导出为单独透明 PNG，桌面批量导出只选择一次目录。框选坐标统一存图像坐标系，推理与选区状态仅在当前页面存活，离开后释放。
- 模板广场使用紧凑页头、连续分类工具栏和响应式流式网格；1520px 默认窗口下文生图使用六列、图生图使用四列，较窄窗口逐级降列。
- 文生图与图生图预览按列宽流式展示，图片保持原始比例，高度随宽度自适应，不能使用 `cover` 裁切或拉伸；卡片信息层级以提示词为主。
- 图生图卡片必须将原图与效果图无间距并排展示；原图覆盖中性暗色蒙版，原图与效果标签放在图片内部，并使用半透明深色底、浅色文字和边界保证不同明暗图片上的可读性。
- 模板卡片的提示词最多显示三行，紧凑场景最多显示两行；套用模板使用仅显示“使用”的紧凑按钮，不能占据整行。
- 创作历史沿用模板广场的页头、模式分段控制和响应式网格；任务卡片以完整结果预览和提示词为主，任务状态叠放在图片右上角，内容区底部只展示积分消耗和创建时间。
- 历史任务卡右键菜单依次提供“打开任务”“复制”“保存”“图生图”，四项操作使用同一菜单层级；后三项针对首张结果图，无结果图片时保持可见禁用。菜单打开时不预选或高亮任何操作，只在悬停或键盘导航时显示交互反馈；浮层限制在窗口可视范围内，并支持 Escape、方向键、Home、End、菜单键和 Shift+F10。打开任务会进入对应生成模式并恢复提示词、生成参数、图生图参考图和服务端结果图片；图生图动作进入新的图生图工作区。
- 点击任意历史任务进入多选状态，失败或无图片任务也可选择；选中卡片同时使用强调边界和勾选标记。底部始终提供删除和取消选择，仅当所选任务均有结果图片时显示描边样式的批量下载按钮；页头不提供清空历史入口。
- 历史分页每页 12 项，使用首尾页、前后页和有限页码按钮；切换文生图或图生图时回到第一页。
- 弹窗使用清晰标题和关闭图标；高度超过视口时只滚动内容区。
- 新弹窗必须支持 Escape、基础焦点管理、`role="dialog"` 和标题关联。
- 更新弹窗使用单一石墨表面、版本对比和线性进度。普通更新可稍后，强制更新不显示关闭操作且 Escape 无效；下载、安装、错误和重启必须同时使用图标或文字表达，不能只靠颜色。

## 8. 动效

- 常规交互：160-180ms ease。
- 抽屉导航：220ms ease。
- 模态框：200ms，轻微位移与透明度变化。
- shimmer 只在真实加载期间运行。
- 必须遵守 `prefers-reduced-motion: reduce`，禁用非必要动画。

## 9. 可访问性

- 交互元素必须可通过键盘到达，并保留可见焦点环。
- 正文与表面目标对比度至少 4.5:1；大字至少 3:1。
- tooltip 同时响应 hover 和 focus，但不能作为唯一可访问名称。
- 不使用颜色作为唯一状态信号。
- 图片提供描述用途的 alt；装饰图标由按钮标签承接语义或隐藏。
- 支持 `prefers-contrast: more`，提高边界与辅助文字对比度。

## 10. 实现约定

- `src/styles/main.scss` 仅通过 `@use` 聚合全局样式，不直接承载具体规则。
- `src/styles/_tokens.scss` 定义主题 tokens，`_foundation.scss` 提供重置与基础表单，`_controls.scss` 提供公共控件，`_patterns.scss` 提供页面、空状态和弹窗等复用模式。
- App、路由 view 和功能组件的私有布局、外观与响应式规则放在对应 SFC 的 `<style scoped lang="scss">` 中。
- 新组件优先复用现有语义类和 tokens，不新增硬编码主题颜色；只有跨两个及以上组件稳定复用的规则才进入 `src/styles/`。
- 不引入 Tailwind、新组件库、在线字体或 Emoji 功能图标。
